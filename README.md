# Snow Time Gudauri — концепт нового сайта

Демо-версия редизайна [snowtime.ge](https://snowtime.ge): новогодняя афиша на первом экране, живой обратный отсчёт, цены проживания с переключением сезона и заявка сразу в WhatsApp.

Один файл `index.html`, без сборки. Цены взяты с текущего сайта и из прайса новогодней ночи — перед запуском их подтверждает владелец. Фото пока заменены заглушками.
